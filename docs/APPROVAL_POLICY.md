# Character and animation approval gate

Existing approved base: headset-wearing AI dolphin with black visor, monochrome 128×64 design, distinct timed actions.

New characters and new animations follow: concept preview → owner review → explicit approval → conversion/packaging → commit.

Fox, penguin, axolotl and any other concept proposals are *not* authorized additions merely because they were generated as examples.

This repository remains independent of both Flipper AI project repositories.
